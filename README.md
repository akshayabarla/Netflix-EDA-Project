# Netflix EDA Project

This project analyzes Netflix Movies and TV Shows data using Python.

## Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Visualizations
- Bar Chart
- Line Chart
- Histogram
- Scatter Plot
- Pie Chart
- Heatmap

## Key Findings
- Movies dominate Netflix content.
- Most content was added after 2015.
- USA contributes the highest number of titles.
